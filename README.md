# Campus Placement and Recruitment Management Portal (CPRMP)

CPRMP is an MCA Semester-3 group mini project designed to support campus placement and recruitment activities.

## Primary Roles

- Student
- Admin / Placement Officer
- Recruiter

## Technology Stack

- Frontend: React.js, Vite, JavaScript, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB Community Server with Mongoose
- Authentication: JWT and bcrypt
- API: REST
- Testing: Jest, Supertest, and Postman
- Version control: Git and GitHub

## Core Features

- User authentication and role-based access
- Student profiles and resume management
- Company and placement drive management
- Deterministic placement eligibility checks
- Applications, shortlisting, and placement tracking
- Assistive AI resume-job matching and skill-gap analysis

AI recommendations are assistive only. They must not override official eligibility rules or recruitment decisions.
